# Glove 80 Initial Thoughts

this is going to be interesting to learn yet {[
	another Split keyboard and maybe
	remap keys.
]}
but the defaults on this keyboard are better e.g.
the esc key is where I remapped the key to on the
moonlander. Actually that is not correct. It's where
I put the ctrl key, and now the control key is on the
thumb cluster. The ctrl key is on the thumb cluster
next to the shift key.

One thing I like about this keyboard is that there are
function keys on it without needing layers. But it
also has layer support. I am going to give this new
keyboard a go with the defaults.

Physically the keys are low profile vs the moonlander
which has what I'd call full-keys. But they still feel
ok. I ordered the "brown" keys which are intermediate
between quiet and loud keys.

One thing I don't like is that the home row f and j keys
don't have a little ridge on them so your fingers know
they are in the right place.
